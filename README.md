# パン作り記録アプリ（IBM-010-C）

## 起動方法
`index.html` をChrome / Edgeなどのブラウザで開いてください。

## 初期状態
- 作成回数 Total 4回
- 2026/9/11 標準パン
- 2026/9/13 標準パン
- 2026/9/20 りんごパン Ver.1
- 2026/9/21 えだまめチーズパン
- IBM-010-C 標準食パン、えだまめチーズパン、基本ケーキ、りんごパン2版を詳細登録
- アイリスオーヤマ公式レシピ／標準メニューを除外せず登録
- レシピ一覧に「パン（HBで完成）／生地・成形パン／その他」フィルターを追加
- 初期表示は「パン（HBで完成）」

## 主な機能
- Total / 品目別作成回数
- レシピ検索・お気に入り
- 自作レシピ登録
- レシピコピーによる改良版作成
- 作成履歴、評価、感想、次回改善
- 写真登録（ブラウザ内に縮小保存）
- IBM-010-C 機種情報
- 公式取説・公式レシピへのリンク
- ChatGPT相談用テキストコピー
- JSONバックアップ / 復元

## データ保存
初期版はブラウザのlocalStorageを使用します。
設定画面からJSONを書き出し、Google Driveへ保存できます。

Google Driveへの「自動同期」はGoogle OAuth Client IDが必要なため、この配布版では未接続です。
OAuth情報を用意すれば、Drive APIによる自動同期を後付けできます。

## 重要
公式レシピの全文転載は避け、詳細未登録のカタログ項目は公式レシピサイトを開く設計です。
初期履歴の評価・感想・写真など未確認項目は空欄にしています。

## v0.5 更新

## v0.7 操作フロー変更
- 「このレシピで作る」: そのレシピ内容をそのままスナップショット保存し、履歴に「作成中」として即追加

- レシピ一覧は、作成実績のあるレシピを上位表示し、直近作成日が新しい順に並べる

## v0.8 修正・差分表示

## v0.19 Google Drive自動再接続
- Google Drive連携済み端末では、アプリ起動時に自動でアクセストークン再取得を試行
- 自動接続成功時はDriveの最新JSONを自動読込
- 通常は「再接続」操作を不要化
- 自動接続に失敗した場合のみ再接続ボタンを使用
- 自動接続失敗時もlocalStorageキャッシュでアプリ利用継続
- Google Driveを正本、localStorageをキャッシュとして扱う方針を維持

## v0.20 データ復旧・Driveマージ修正
- Driveデータで端末データを丸ごと上書きしない方式に変更

## v0.21 履歴評価の端末間同期修正
- 履歴レコードに updatedAt を持たせ、同じ履歴IDでは新しい更新を優先
- Drive読込時に履歴を丸ごと上書きせず、Driveと端末キャッシュをID単位でマージ
- 更新時刻が同じ/未設定の場合は、評価・コメント・写真など情報量が多い方を優先
- Driveからマージ後、その結果をDriveへ書き戻して他端末でも反映
- カスタムレシピのIDマージは維持


## v0.22 Driveデータ形式互換修正

- 読込後は現行形式でDriveへ保存し直すため、以後の形式を統一
